# 안양시 실제 행정구역 GeoJSON 추가 위치

공식·검증 가능한 원천에서 받은 안양시 행정경계(만안구+동안구 합집합)를 WGS84(EPSG:4326) GeoJSON 형식으로 변환해 이 디렉터리에 **anyang.geojson** 이름으로 넣으세요.

폴리곤 경계선에 있는 좌표는 내부로 판정합니다. 현재는 파일을 의도적으로 넣지 않았으며, 시연용 직사각형을 공식 경계처럼 표시하지 않습니다.

팀원과 반드시 경계 데이터의 출처, 취득일 및 변환 좌표계를 확인하세요. 참고 자료: [SGIS 개발지원센터](https://sgis.mods.go.kr/developer/).
