# 프론트엔드 QA 체크리스트

## 기본 기능

- [ ] 처음 실행하면 분석 결과가 비어 있고 Mock 안내가 보인다.
- [ ] 업종/반경 선택, 지도 클릭 또는 빠른 위치 선택이 작동한다.
- [ ] 위치를 선택하기 전에는 분석 버튼이 비활성화되어 있다.
- [ ] 분석 버튼을 누르면 로딩 중임을 보여주고, 완료 후 결과를 표시한다.
- [ ] 매출은 원→만원으로 변환되어 보인다.
- [ ] 가상 데이터라는 문구가 결과와 리포트에 명확히 붙는다.
- [ ] 결과 저장 후 비교 그래프에 항목이 나타난다.
- [ ] 같은 업종·반경에서는 3개까지만 저장할 수 있다.
- [ ] 동일 조건/근접 좌표를 다시 저장하지 않는다.
- [ ] 비교 후보지 삭제가 동작한다.
- [ ] 새로고침해도 localStorage에 저장한 후보지가 남는다.
- [ ] 업종/반경 변경 시 다른 조건 결과를 혼합 비교하지 않는다.
- [ ] GPT 리포트 요청과 결과 표시가 작동한다.

## 오류 상황 (테스트 모드의 '개발자 테스트' 펼치기)

- [ ] 데이터 없음 → '데이터가 없습니다' 안내
- [ ] 모델 오류 → 재시도 안내
- [ ] 서버 오류 → 재시도 안내
- [ ] 잘못된 JSON → '응답 형식 오류' 안내
- [ ] 리포트 오류 → 기본 매출 분석 유지, GPT 오류만 표시
- [ ] 느린 분석 중 업종 변경 → 이전 결과가 새 화면에 표시되지 않음
- [ ] 임시 테스트 영역 밖 클릭 → 선택 위치가 바뀌지 않음
- [ ] 지도 경계선 클릭 → 영역 내부로 인정 (자동 테스트 포함)

## 백엔드 연동 전 마지막 검증

- [ ] `npm test` 통과
- [ ] `npm run build` 성공
- [ ] 실제 브라우저에서 지도 타일이 정상 로딩
- [ ] 모바일 화면에서 버튼·그래프가 잘리지 않음
- [ ] `.env` 파일이 GitHub에 올라가지 않음
- [ ] 실제 API URL, CORS, 오류 코드 확인
- [ ] 행정경계 좌표계 WGS84 및 백엔드 판정과 일치 확인
- [ ] 모델이 제공하지 않는 지표는 `null`로 반환, UI는 '자료 없음' 표시
