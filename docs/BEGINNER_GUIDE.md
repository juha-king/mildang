# 프론트엔드를 처음 하는 팀원을 위한 학습 및 수정 순서

## 어떤 파일을 먼저 보면 될까?

1. **`src/App.jsx`**: 화면과 상태(업종, 지도 선택, 분석 결과)를 관리합니다. 버튼의 `onClick`이 어떻게 동작하는지 찾아보세요.
2. **`src/components/AnyangMap.jsx`**: 지도에서 클릭 좌표를 부모 `App.jsx`로 보내는 방법을 살펴봅니다.
3. **`src/services/api.js`**: Mock 응답과 실제 FastAPI 요청을 구분합니다. 마지막에 백엔드 연결할 때 수정할 핵심 파일입니다.
4. **`src/lib/contracts.js`**: 요청·응답 값이 정확한지 검증합니다.
5. **`src/lib/history.js`**: 후보지 저장과 비교 조건을 관리합니다.
6. **`src/styles.css`**: 색상, 간격, 크기 등 디자인은 나중에 여기서 조절합니다.

## 실습 순서

1. 앱을 실행하여 업종과 위치를 선택하고 분석합니다.
2. `src/lib/contracts.js`의 `INDUSTRIES`에서 임시 업종 이름 한 개를 수정합니다. 화면이 바뀌는지 확인합니다.
3. `src/services/api.js`의 `mockAnalyze()`에서 `competitor_count`를 `null`로 바꿔 '자료 없음'을 확인합니다.
4. 테스트 시나리오를 '데이터 없음'으로 바꾸고 메시지를 확인합니다.
5. `src/App.jsx`의 `ComparisonBars`에서 막대 그래프를 만드는 코드를 읽습니다.
6. `npm test`를 실행하여 검증 결과를 확인합니다.

## 주의

- `.env` 파일은 Git에 올리지 않습니다.
- 모델 예측 결과를 브라우저에서 계산하지 않습니다. `mockAnalyze()`는 시제품에만 필요합니다.
- 모델 측 입력 기준 확정 전에 업종이나 반경을 최종 스펙으로 못 박지 않습니다.
- 카카오맵 JavaScript 키는 웹 SDK용 공개 식별 키이고, GPT/카카오 REST 비밀키와는 다릅니다. 비밀키는 절대 프론트엔드에 넣지 마세요.
